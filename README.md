# House Price Prediction using Linear Regression

## Project Overview

This project predicts house prices using the California Housing Dataset and a Linear Regression model.

## Features Used

- Median Income
- Average Rooms
- House Age
- Average Occupancy
- Latitude

## Machine Learning Model

Linear Regression

## Evaluation Metrics

- RMSE
- R² Score

## Visualization

Predicted vs Actual House Prices Scatter Plot

## Technologies

- Python
- Pandas
- Matplotlib
- Scikit-learn
